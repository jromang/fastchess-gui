## Fallback font

Droid Sans, Copyright Google Inc., Apache License 2.0, taken from Dear ImGui (`misc/fonts/DroidSans.ttf`).
Only used when none of the usual system fonts (Noto Sans, DejaVu Sans, Liberation Sans, Segoe UI, Tahoma,
Arial) is installed.
