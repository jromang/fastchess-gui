A fix for the Folder buttons on Windows. (0.4.5 had the same fix but was never released: its build could not
install the packages it needs.)

## Fixes

- **The Folder buttons open the folder on Windows**, in the list of tournaments and in a tournament's page. The path
  went to Windows as a `file://` link that Explorer could refuse, and nothing said so. Explorer now gets the path
  itself; on Linux the link is properly escaped (spaces, accents, `#`).
- When the system still cannot open a folder or a file (Folder, Engine log), a message shows the path and the
  system's reason, and the path is copied to the clipboard to paste in the file manager.

## Downloads

| File | Contents |
|---|---|
| `fastchess-gui-v0.4.6-linux-x86_64.tar.gz` | `fastchess-gui` and the `fastchess` command line tool, x86-64 Linux (glibc 2.35 or newer). Needs X11 or Wayland and OpenGL 3.2. |
| `fastchess-gui-v0.4.6-windows-x86_64.zip` | `fastchess-gui.exe` and `fastchess.exe`, 64-bit Windows 10 or newer. No installer, nothing else to install. |
| `SHA256SUMS.txt` | Checksums of the two archives. |

The binaries are built by this repository's GitHub Actions workflow; the tests run on Linux and on Windows.
