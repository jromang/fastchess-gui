A bug-fix update of fastchess-gui, still built on fastchess 1.8.2-alpha (upstream commit `a281caf`).

## Changes

- Engines now have 60 seconds to answer `uciok`, both when their UCI options are read and when a game starts.
  fastchess allows 10 seconds by default, which is too short for engines that load a large network before
  reading their input, on a slow machine or on a first launch that the antivirus scans: the options of such an
  engine did not appear, and its games could not start.

## Downloads

| File | Contents |
|---|---|
| `fastchess-gui-v0.2.1-linux-x86_64.tar.gz` | `fastchess-gui` and the `fastchess` command line tool, x86-64 Linux (glibc 2.35 or newer). Needs X11 or Wayland and OpenGL 3.2. |
| `fastchess-gui-v0.2.1-windows-x86_64.zip` | `fastchess-gui.exe` and `fastchess.exe`, 64-bit Windows 10 or newer. No installer, nothing else to install. |
| `SHA256SUMS.txt` | Checksums of the two archives. |

The binaries are built by this repository's GitHub Actions workflow; the tests run on Linux and on Windows.

## Known limitations

- Two engines per match (no gauntlet or round robin yet).
- No Chess960 option in the interface.
- The Windows build has been tested under Wine and by the automated tests on Windows, but has seen little real use
  yet.
