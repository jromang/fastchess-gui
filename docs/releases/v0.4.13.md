The PGN files of a tournament are named after it (#85).

## Changes

- A new tournament writes its games to `<name>.pgn` and `<name>-chessbase.pgn` in its folder, instead of
  `games.pgn` and `games-chessbase.pgn`. Characters Windows does not allow in a file name are replaced with `_`,
  and long names are cut. The names are chosen when the tournament is created and stay the same if it is renamed.
  Tournaments created before, and matches imported from 0.2.x, keep `games.pgn`.
- *Export all* proposes `<name>.pgn` next to the tournament's folder, and an export onto the tournament's own PGN
  files is refused. Before, choosing `games.pgn` as the target emptied it.
- A tournament with named PGN files is refused by 0.4.12 and earlier versions, as written by a newer version: they
  would have written a `games.pgn` of their own beside it.
