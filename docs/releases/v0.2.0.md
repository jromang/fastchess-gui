A small update of fastchess-gui, still built on fastchess 1.8.2-alpha (upstream commit `a281caf`).

## Changes

- *CPU affinity* is now off by default. fastchess pins each game, both engines included, to a single processor:
  with two concurrent games only two cores were busy and the others stayed idle, which could make engines run
  much slower than expected.
- The help text of the option and the user guide explain this behaviour.

A setup saved by v0.1.0 keeps its affinity setting: untick *CPU affinity* in the concurrency settings if it was
on.

## Downloads

| File | Contents |
|---|---|
| `fastchess-gui-v0.2.0-linux-x86_64.tar.gz` | `fastchess-gui` and the `fastchess` command line tool, x86-64 Linux (glibc 2.35 or newer). Needs X11 or Wayland and OpenGL 3.2. |
| `fastchess-gui-v0.2.0-windows-x86_64.zip` | `fastchess-gui.exe` and `fastchess.exe`, 64-bit Windows 10 or newer. No installer, nothing else to install. |
| `SHA256SUMS.txt` | Checksums of the two archives. |

The binaries are built by this repository's GitHub Actions workflow; the tests run on Linux and on Windows.

## Known limitations

- Two engines per match (no gauntlet or round robin yet).
- No Chess960 option in the interface.
- The Windows build has been tested under Wine and by the automated tests on Windows, but has seen little real use
  yet.
