First release of fastchess-gui, a desktop front end for the [fastchess](https://github.com/Disservin/fastchess)
tournament manager, built on fastchess 1.8.2-alpha (upstream commit `a281caf`).

## What it does

- Matches between two UCI engines: fixed number of games, unlimited, or SPRT (normalized, logistic or BayesElo
  model). Time control or fixed nodes. Concurrency detected at startup.
- Live view of every concurrent game: board, clocks, running search (depth, score, nodes, nps, PV), move list and
  evaluation curve.
- Pause and resume without losing results, stop after the running games or immediately.
- Finished games with replay; every game is written to a cutechess style PGN and to a ChessBase / Lichess style
  PGN (`[%eval]`, `[%clk]`, `[%emt]`).
- Elo, nElo, LOS, pentanomial counts and LLR, with charts.
- UCI option editor, opening books, draw / resign / max moves / Syzygy adjudication, crash recovery, end of
  match notification.
- English and French interface, following the system language.

## Downloads

| File | Contents |
|---|---|
| `fastchess-gui-v0.1.0-linux-x86_64.tar.gz` | `fastchess-gui` and the `fastchess` command line tool, x86-64 Linux (glibc 2.35 or newer). Needs X11 or Wayland and OpenGL 3.2. |
| `fastchess-gui-v0.1.0-windows-x86_64.zip` | `fastchess-gui.exe` and `fastchess.exe`, 64-bit Windows 10 or newer. No installer, nothing else to install. |
| `SHA256SUMS.txt` | Checksums of the two archives. |

The binaries are built by this repository's GitHub Actions workflow; the tests run on Linux and on Windows.

## Known limitations

- Two engines per match (no gauntlet or round robin yet).
- No Chess960 option in the interface.
- The Windows build has been tested under Wine and by the automated tests on Windows, but has seen little real use
  yet.
