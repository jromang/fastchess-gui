A bug-fix update of fastchess-gui, still built on fastchess 1.8.2-alpha (upstream commit `a281caf`).

## Changes

- On Windows, an engine whose file name contains a space is now started correctly. The path was passed to
  Windows unquoted, so Windows split it at its spaces and could start another program: with
  `gaiachess-windows-console.exe` in the same folder as `gaiachess-windows-console 4.4.1.exe`, the GUI ran the
  former with the argument `4.4.1.exe`. The engine exited at once, its UCI options did not appear and the GUI
  reported *Engine didn't respond to uciok after startup*.

## Downloads

| File | Contents |
|---|---|
| `fastchess-gui-v0.2.2-linux-x86_64.tar.gz` | `fastchess-gui` and the `fastchess` command line tool, x86-64 Linux (glibc 2.35 or newer). Needs X11 or Wayland and OpenGL 3.2. |
| `fastchess-gui-v0.2.2-windows-x86_64.zip` | `fastchess-gui.exe` and `fastchess.exe`, 64-bit Windows 10 or newer. No installer, nothing else to install. |
| `SHA256SUMS.txt` | Checksums of the two archives. |

The binaries are built by this repository's GitHub Actions workflow; the tests run on Linux and on Windows.

## Known limitations

- Two engines per match (no gauntlet or round robin yet).
- No Chess960 option in the interface.
- The Windows build has been tested under Wine and by the automated tests on Windows, but has seen little real use
  yet.
