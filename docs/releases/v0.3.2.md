WinBoard engines, and a window that always fits the screen.

## Changes

- **WinBoard engines** (xboard protocol) are played like UCI ones. fastchess only speaks UCI: fastchess-gui
  translates, the way WinBoard itself drives an engine (checked against the protocol specification, xboard's
  source, cutechess, Banksia and python-chess):
  - protocol 2 features, or protocol 1 for engines that send none; `ping` when the engine has it;
  - positions with `setboard`, or edit mode; moves in coordinates or SAN, with or without `usermove`;
  - `level`, `time`/`otim`, `st`, `sd`, `nps`; `hard`/`easy`; the `white`/`black` commands old engines expect;
  - thinking output (depth, score, mate scores old and new, time, nodes, PV in SAN, long algebraic or
    coordinates) shown live and written to the PGN;
  - the engine's options, `memory`, `cores` and Syzygy path, as UCI options in the engine table;
  - resignation (also on the opponent's move), result claims, `Illegal move` and `Error` replies, a move still
    owed by a stopped search, an engine that loses track of the game (set up again).

  The protocol of an engine is found out when it is added, or chosen in its settings. Engine lists imported from
  ChessGUI, cutechess, Banksia or Arena keep their WinBoard engines. Tried with GNU Chess 6, Phalanx XXV,
  Fairy-Max 5, HoiChess and TSCP 1.81, in tournaments with Stockfish.
- **The window fits the screen**: on a screen smaller than 1440×900 times the display scale (a 1080 pixel screen
  at 125 %, a laptop at 100 %), the window opened taller than the screen, its title bar and close button above
  the top edge. It now opens inside the usable area of the screen, maximized when the default size does not fit.
- A **Quit** button at the bottom of the left rail.

## Known limitations

- WinBoard engines: no Chess960, no option for engines that report scores from White's point of view, and
  engines asking to be restarted for every game (`reuse=0`) are not (tick *Restart the engine for every game*).
  An engine of protocol 1 without `setboard` nor edit mode can only start from the initial position.
- The TLCS server has been checked against node-tlcv's documentation and source and a client written from it,
  not yet against TLCV itself or a running node-tlcv.
- Only the last change of a tournament can be undone, and only until the next game starts.
- On Wayland, detached boards stay inside the main window.
- No Chess960 option in the interface.
