The fixes of an audit made after 0.4.10 (#47 to #54): a crash on resume, large engine libraries, files that
survive a power cut, the network, and large tournaments.

## Fixes

### Tournaments (#47)

- **Resuming a tournament could crash.** The games already played were counted over two copies of the results
  (a 0.4.6 regression).
- **Stop when idle now ends after a resume**, a voided game or a withdrawal. It used to wait for the other game of
  a pair that had none left.
- **A queued tournament that cannot start stays in the queue**, and the ones after it start.
- A withdrawal that drops the last running game now ends the tournament.
- **Knockout:** the tied matches of a round play their tiebreaks together. After ten tiebreaks the better seed goes
  through.
- **An engine that fails to start is tried again** three times, 10 s apart, before the tournament stops.
- The standings order no longer depends on the order of the games when head to head goes round in a circle.
- The headless counter no longer counts voided games.

### Engines (#48, #49, #52)

- **Start, Resume and the queue wait for the engine being read** instead of refusing. Before, a large import
  blocked Start for as long as the list took to read. The tournament's engines are read first, and a queued engine
  can be read next from its menu.
- **Check sends the engine's options.** A wrong `EvalFile` or an option the engine does not have no longer passes.
  A failed read or check shows the engine's last lines.
- A read that was outdated before it ended (new program, new protocol) is done again rather than kept.
- Quitting during a read or a check no longer freezes the window.
- **Importing a list or a folder again adds only the new engines.** An import shows its engines before adding them.
- **Renaming an engine is followed everywhere:** the tournament's participants, the queue, the test suite.
- The checksums of new programs are computed in the background: no more freeze after an import.
- **For large libraries:**
  - search by program and reported name, and a state filter (works, failed, not checked, missing, WinBoard);
  - several engines selected with Ctrl or Shift: Check, Add to a group, Remove;
  - "Check those not checked" and "Remove the missing programs";
  - a "…" button for file and folder options;
  - a search field in every engine list.
- **Windows:**
  - an old engine missing a DLL fails at once instead of waiting on an error box;
  - engines end with everything they started, even if the GUI crashes.

### Files (#50)

- **The games and the journal survive a power cut.** The games are written to disk before the journal points to
  them, write errors stop the tournament with a message, and a damaged journal line is skipped.
- **`engines.json` is synced and kept as `engines.json.bak`**, and is no longer rewritten at every key. A failed
  save is reported.
- **Two programs can no longer play the same tournament folder.** The second one only shows it.

### Network (#51)

- **Editing the lichess fields no longer freezes the window or creates stray broadcasts.** They apply when the
  edit ends, and the relay stops without blocking.
- **A slow or silent client can no longer stall the web page or the window.**
- **The TLCS server sends nothing large to an address that has not answered**, and limits logons.
- A port already in use is reported, on Windows too.
- The lichess token's file keeps its private permissions on Linux.

### Interface and large tournaments (#53, #54)

- **Ratings of a big PGN (CCRL, CEGT) are computed in seconds**, in the background. They used to freeze the window
  for minutes.
- **Schedule, Overview and Openings are recomputed only when a game ends.** They used to be recomputed at every
  frame.
- **Standings:**
  - a Table view (Buchholz, SB, health) for Swiss, gauntlets and large fields, and the crosstable for round robins;
  - both views draw only the rows in sight.
- The Tournaments page and a big tournament's games are read in the background.
- Idle engine processes are limited during a tournament, and those of withdrawn participants end.
- **Live files:**
  - names with quotes are escaped in the PGN;
  - the folder applies when the edit ends;
  - on Windows, `live.pgn` is written even while another program reads it.
- **SPRT bounds the wrong way round are refused before Start.**
- **Templates:**
  - characters Windows forbids are replaced;
  - errors are shown;
  - replacing a template asks first.
- The replay keys no longer act while typing, and the move lists follow the current move.
- The interface scale follows the window to a screen with another scale.
- The remaining untranslated text is translated, and the journal no longer stores text in the user's language.
