Five new languages, a list of engines easier to read, and the fixes of a review of the whole program.

## New

- **Spanish, Italian, Brazilian Portuguese, Russian and simplified Chinese**, next to English, French and German.
  The interface follows the language of the system, or the one chosen in **Settings**. These translations are new:
  corrections are welcome (the `.po` files of `gui/i18n`, which Poedit opens). Chinese uses a font of the system:
  Microsoft YaHei on Windows, Noto Sans CJK or WenQuanYi on Linux.
- Counts take the right plural in every language ("1 partie", "2 parties"; "1 партия", "3 партии", "5 партий").
- **Engines:** the list is in alphabetical order. Hovering an engine says what its mark means: ✓ it works, ! a
  problem, with what was found, ↔ a WinBoard engine, · not checked yet. A right click checks an engine, reads its
  options again, duplicates or removes it; the Delete key removes the selected engine, after asking (#45).

## Fixes

- **The Folder buttons open the folder on Windows**, in the list of tournaments and in a tournament's page. When the
  system still cannot open a folder or a file, a message gives the path and the reason, and the path is copied.
- **Windows engines find their books and networks in folders with accents** (C:\Échecs…): option values are now
  given in the engine's own code page, or as the short name of the file, instead of UTF-8 it could not read (#46).
- An engine list (engines.json) or another file of the profile that cannot be read is kept aside as
  `<name>.unreadable` instead of being replaced by an empty list when the program quits.
- No more quitting: at every start with a settings.json of another shape, when checking an engine in a folder
  that cannot be read, when a network folder stops answering while the tournaments are listed, or when exporting
  the games of two players whose names cannot be file names.
- Tournaments changed while they run:
  - a game of a replaced engine still being played is played again by its successor, instead of counting for the
    old engine;
  - games of a withdrawn engine still being played no longer show up;
  - a game that ends during a change is listed once;
  - undoing an added engine, then adding another, shows the right name.
- Reading or checking an engine stays with that engine when another one is removed meanwhile.
- Right numbers: games per hour after resuming a tournament with voided games, the preview of a change in a Swiss
  or a knockout, and the score of an engine that had byes.
- Smaller: the Start button's tooltips, the schedule's cycle headers when a cycle comes in two blocks, the lichess
  broadcast name cut inside a character, engines imported twice with paths in another case on Windows.

0.4.5 and 0.4.6 were not released: their builds could not install the packages they needed.

## Known limitations

The limitations of 0.4.3 still hold. Windows before 10 version 1903 is not tested: paths with accents may fail there (#46).
