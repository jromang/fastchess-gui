Long engine lists: options read when asked, and no more waiting at every start.

## Fixes

- **Reading an engine's options is never dropped** (#45). Asked for while another engine was being read (Read the UCI
  options again, a new protocol, the reading after a check), it did nothing. It now goes first in the queue, and
  the button says "Reading…" or "Waiting to be read…".
- **No long queue at every start.** Every engine without options was read again at each start, broken and WinBoard
  ones included: with hundreds of engines it lasted minutes. Each version now reads such an engine once. Engines an
  earlier version refused (Cerebro 3.03d, Amyan 1.72) are read again after the update, then left alone.
- **Start no longer waits for the whole list to be read**, only for the engines of the tournament.
