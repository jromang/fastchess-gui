Chess960.

## Changes

- **Chess960** (Fischer random), with UCI and WinBoard engines alike. Tick *Chess960* in the openings of a new
  tournament: without a book, the games start from the 960 starting positions in random order; with a book, from
  its positions. The engines must play Chess960 (the `UCI_Chess960` option of a UCI engine, the `fischerandom`
  variant of a WinBoard engine): the summary names those that do not, and such a tournament does not start.
- WinBoard engines play Chess960 as WinBoard has them do: `variant fischerandom`, positions in X-FEN, castling
  written `O-O`/`O-O-O` both ways. Tried with Sjaak II against Stockfish.
- Games, PGN files, the live view and the broadcasts show Chess960 games with their castling.

## Known limitations

- WinBoard engines: no option for engines that report scores from White's point of view, and engines asking to be
  restarted for every game (`reuse=0`) are not (tick *Restart the engine for every game*). An engine of protocol 1
  without `setboard` nor edit mode can only start from the initial position.
- The TLCS server has been checked against node-tlcv's documentation and source and a client written from it,
  not yet against TLCV itself or a running node-tlcv.
- Only the last change of a tournament can be undone, and only until the next game starts.
- On Wayland, detached boards stay inside the main window.
