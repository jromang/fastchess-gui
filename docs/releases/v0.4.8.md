Engines that describe their options badly can be used again.

## Fixes

- **Engines whose UCI options are described badly are read, checked and played** (#45). An option line the engine
  gets wrong (Amyan 1.72: `MultiPV type spin default 1`, without min and max; Cerebro 3.03d: `NalimovCache` with a
  default outside its own range) made the whole engine refused: no option was shown, and no game could start. Such
  an option is now kept, listed and settable; the engine itself judges the value.
- In the options table, a number option without bounds is no longer stuck at 0.
- A translated text holding a `%` can no longer be read as a format by the interface.
- Without an opening book, the log no longer gets two warnings from fastchess at every start: the setup already
  says it, in the language of the interface.
