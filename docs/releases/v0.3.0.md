fastchess-gui becomes a tournament manager, on top of the two-engine SPRT match it already was. Built on
fastchess 1.8.3-alpha.

## New

- **Tournaments**: round robin (Berger tables, any number of cycles), gauntlet, Swiss (paired as results come,
  no rematch, byes) and knockout (seeded bracket with byes, tiebreak game pairs). Each engine can have its own
  Hash, Threads, fixed nodes and time odds.
- **Standings** with maximum likelihood ratings and their 95 % intervals, an anchor, Sonneborn-Berger or
  Buchholz, the crosstable, and export as text (for a forum post) or HTML. A bracket view for knockouts.
- **Exact resume**: every tournament is a folder with an append-only journal. After a stop, a crash, a closed
  window or a power cut it continues with no game lost or played twice, with the statistics of the games
  already played.
- **Changes while it runs**: add, withdraw or replace an engine, change the number of cycles, play games again
  or void them, with the impact shown before applying. The last change can be undone until the next game starts.
- **Live view**: every game in progress as a mosaic, or one in focus; boards can be detached into their own
  windows.
- **Broadcast**: live PGN, HTML standings and JSON files written as the games go, a TLCS server for TLCV and
  other viewers, and a built-in web page.
- **Engine library**: health check, groups, a reference Elo, import of ChessGUI, cutechess, Banksia and Arena
  engine lists, WinBoard engines through a UCI adapter such as PolyGlot.
- **Workflow**: a queue of tournaments, *Relaunch with…* a new engine version, templates, and a headless mode,
  `fastchess-gui --run FOLDER|SETUP.json`, for servers.
- **Ratings**: one rating list over every game of every tournament, by time control, anchored on a reference Elo,
  exported as text or CSV.
- **A new interface**: a navigation rail, a home page listing every tournament, light and dark themes, the Inter
  font and Lucide icons embedded. The tournaments folder can be chosen in the settings.

The two-engine match is still one page away: *New tournament*, format *Match*, two engines, *Start*.

## Upgrading

- Matches played with 0.2.x appear on the home page: *Import them* turns them into finished tournaments.
- The light theme is now the default, but a setup saved by 0.2.x keeps *Automatic (system)*: choose the theme
  in **Settings**.
- fastchess-gui no longer writes fastchess' `config.json` in a tournament folder; `tournament.json` and
  `journal.jsonl` replace it.

## Known limitations

- The TLCS server follows the protocol as TLCV and node-tlcv document it, but has not been tried with a real
  TLCV client yet.
- Only the last change of a tournament can be undone, and only until the next game starts.
- On Wayland, detached boards stay inside the main window.
- No Chess960 option in the interface.
- The Windows build is tested by the automated tests on Windows and under Wine, but has seen little real use.
