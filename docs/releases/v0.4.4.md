A fix for engine lists imported from other programs.

## Fixes

- **No more quitting a couple of seconds after start** after importing engines (from cutechess, Arena, ChessGUI…).
  An engine that writes its name, author or options with accents in the old Windows encoding (Windows-1252, Latin-1),
  as many old engines do, made the engine list impossible to save: the program ended when the background reading
  of the imported engines' options got to it, and again at every start. Such text is now read as Windows-1252 and
  shown with its accents; the engines already imported are kept.
- Engine lists of Windows programs written in Windows-1252 are imported with their accents, in names and paths.
- No file of the profile or of a tournament (engines, journal, broadcast) can fail to be written because of text
  that is not UTF-8: such bytes are replaced with "�".
- Reading an engine's options no longer fails on a path that cannot be accessed (a network drive that is gone…).
