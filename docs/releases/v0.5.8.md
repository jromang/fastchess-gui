The copied standings now say where they come from.

## Standings

- The copies of the standings (text and BBCode, the table or a gauntlet's table) end with a line naming the program
  and its version, such as `fastchess-gui 0.5.8`, and the line under the header of a gauntlet's table is drawn with
  `=` instead of `-`. The columns and the line under the table are as before. A table posted on a forum is thus told
  apart from those of other GUIs at a glance.

## Downloads

| File | Contents |
|---|---|
| `fastchess-gui-v0.5.8-linux-x86_64.tar.gz` | `fastchess-gui` and the `fastchess` command line tool, x86-64 Linux (glibc 2.35 or newer). Needs X11 or Wayland and OpenGL 3.2. |
| `fastchess-gui-v0.5.8-windows-x86_64.zip` | `fastchess-gui.exe` and `fastchess.exe`, 64-bit Windows 10 version 1903 or newer. No installer, nothing else to install. |
| `SHA256SUMS.txt` | Checksums of the two archives. |

The binaries are built by this repository's GitHub Actions workflow; the tests run on Linux and on Windows. The
archives carry the licenses of the libraries built in (see `ATTRIBUTION.md`).
