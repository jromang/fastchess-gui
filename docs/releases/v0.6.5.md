Ending a game in progress with a result, on macOS too; a build from source without warnings.

## macOS

- *End with result*, in a live board's right-click menu and in the command palette, ends a game being played on a
  Mac as elsewhere: the engine on move is stopped, the game counts with the result chosen, and the tournament goes on.
  It was refused on macOS since 0.6.0, after a failure on the Macs of the build service; that failure came from the
  test itself, and a tester's trace on a real Mac showed the action working as on Linux.
- The guide no longer says it is not available on macOS, in every language.

## Building from source

- The build gives no warning any more, with GCC and clang, on macOS, on Linux (ARM included) and for Windows.

## Downloads

| File | Contents |
|---|---|
| `fastchess-gui-v0.6.5-linux-x86_64.tar.gz` | `fastchess-gui`, x86-64 Linux (glibc 2.35 or newer). Needs X11 or Wayland. |
| `fastchess-gui-v0.6.5-windows-x86_64.zip` | `fastchess-gui.exe`, 64-bit Windows 10 version 1903 or newer. No installer, nothing else to install. |
| `fastchess-gui-v0.6.5-macos-universal.zip` | `fastchess-gui.app`, macOS 13.3 or newer, Apple silicon and Intel. Not signed: Control-click it and choose Open the first time. |
| `SHA256SUMS.txt` | Checksums of the three archives. |

The binaries are built by this repository's GitHub Actions workflow; the tests run on Linux, Windows and macOS. The
archives carry the licenses of the libraries built in, of the piece sets and of the 3D board's pieces and tone mapping
(see `ATTRIBUTION.md`).
