For engine testers who run test after test: losses on time in the standings as they happen, and one PGN file for
all their games, the two games of an opening side by side.

## Changes

**Standings**
- **TF**, each engine's losses on time, in a column of the overview's standings and of the crosstable, in orange
  as soon as there is one: an engine whose time management is wrong shows while the tournament runs, and can be
  withdrawn without stopping it (*Change the tournament*, in the Schedule tab), rather than found in the PGN afterwards. The *!* beside
  an engine's name stays for crashes and illegal moves.

**PGN**
- **One PGN file for every tournament**, like cutechess' `-pgnout`: *Also append every game to* in the PGN section
  of a new tournament, with the comment style (ChessBase / Lichess or cutechess). The file is never overwritten,
  several tournaments may share it, the setup remembers it for the next tournament, and a resumed tournament goes
  on writing there.
- Its games come **in schedule order**, whatever order they end in: the two games of an opening side by side
  (A40-A40, E88-E88), rounds in order. A game waits there until those before it are written; a replayed game is
  written when it ends; when the tournament ends, everything left.
- A file that cannot be written (open in another program that locks it, moved) does not stop the tournament: the
  games wait, are tried again after each game, and the overview says so.
- *Export all* and *Export filtered* of the Games tab follow the schedule too.

## Known limitations

- `games.pgn` and `games-chessbase.pgn` in the tournament folder stay in the order games end: the tournament finds
  each game by its place there. The file of *Also append every game to* is the one in schedule order.
- A crash of the program right after games were appended to that file, before they were noted in the journal,
  writes them a second time when the tournament is resumed.
- The copied standings (text, BBCode), the HTML export and the headless mode do not show the TF column yet.
- The limitations of 0.4.2 still hold (lichess rounds of 64 games, replay charts that need their PGN fields, the
  TLCS server tried with node-tlcv only, detached boards inside the main window on Wayland…).
